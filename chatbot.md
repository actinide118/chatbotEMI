## choix 2
Les médias sont des objets complexes, qui entremêlent notamment trois dimensions :

    - une technologie de communication : Internet, support numérique, réseaux de télécommunications, imprimerie, diffusion hertzienne, par câble, par satellite, pressage (CD, DVD), etc.

    - un support de communication : livre, journal, magazine, Web, télévision, radio, etc.

    - une source d'information (en tant qu'entreprise) : un titre de journal, un groupe de presse, une chaîne de télévision, un opérateur de télécommunications, un fournisseur d'accès à  Internet (FAI), un éditeur, un site web, un blog, etc.
